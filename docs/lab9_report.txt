1. REPRODUCIBLE CONTAINER IMAGE
====================================================================

Base Image: python:3.11-slim
Justification:
  - 150MB vs 900MB for full python:3.11 (smaller footprint)
  - Python 3.11 is 10-60% faster than 3.10
  - All project dependencies (LangChain, FastAPI, yfinance) compatible
  - Slim variant = fewer CVEs = smaller attack surface

Layer Order (Optimized for Build Caching):
  FROM python:3.11-slim        # Base (cached permanently)
  RUN apt-get install          # System deps (cached unless changed)
  COPY requirements.txt .      # Deps file (cache invalidated if deps change)
  RUN pip install -r ...       # Packages (cached unless requirements change)
  COPY . .                     # App code (rebuilds on any code edit)

  Why this order: pip install (8-10 min) only re-runs when requirements.txt
  changes. Code edits rebuild only the final layer (<1 second).
  
  Justification: Requirements copied BEFORE application code.
  This exploits Docker build cache: pip install only re-runs when
  requirements.txt changes, saving 8-10 minutes per rebuild.
  Code changes only trigger Layer 6 rebuild (<1 second).

Multi-Stage Build: Not used. Build dependencies (gcc) needed at runtime.
